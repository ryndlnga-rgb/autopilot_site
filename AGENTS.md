# Public research museum

- This directory is the public package. Do not copy credentials, conversations, raw provider responses, service addresses, absolute workstation paths, or infrastructure logs here.
- Preserve the existing E1, E2, E3 sites, generators, experiment outputs, and `latexs/`. The museum pipeline reads them and writes only its own output.
- Every published page must be a self-contained HTML file: inline CSS, JavaScript, data, fonts if any, and illustrations. No CDN, fetch(), remote fonts, or separate runtime assets.
- `index.html` is the entrance. E1, E2, and E3 are connected chapters; mini-exhibits remain directly navigable.
- Explain questions, methods, evidence, implications, and limitations. Separate illustrations from recorded observations.
- Reuse the existing multi-path graph animation; retain stepping, scrubbing, route focus, and visible crash boundaries.
- Use audited methodology outputs for numbers. The manuscript provides the scientific narrative; draft table values may predate corrections.
- Correctness includes all trials. Distinguish Goal, valid non-repeating execution, and continuity. Never imply coverage is correctness or model latency is full failover time.
- Within a recovery condition, weight supported prefix metrics by trial count; give model × graph conditions equal weight in combined summaries. Report singleton/pair support.
- Provide keyboard operation, visible focus, readable contrast, responsive layouts, pause controls, and reduced-motion behavior.
- Verify data counts, source immutability, offline operation, links, and the key visitor journeys before claiming the build works.
