# Pip sprite

`pip-parcel-robot.png` was generated with the built-in imagegen tool for this prototype. It has a transparent background and is embedded as a data URI in both game levels. The image is decorative; game position and state also have text descriptions.

Generation prompt:

> Use case: stylized-concept. Asset type: transparent pixel-art game avatar for a retro delivery route game on a navy background. Primary request: Exactly one sprite of Pip, a tiny friendly cardboard parcel delivery robot. Warm ochre cardboard box body with shipping tape, two simple dark eyes, small teal wheels or treads, tiny lime accent. Three-quarter view facing right. Style/medium: crisp chunky pixel art, intentionally simple silhouette readable at 48px, hard square pixel edges, limited warm gold/lime/teal palette with dark outlines. Composition/framing: single centered full-body robot, generous transparent margin, square canvas. Scene/backdrop: genuinely transparent background. Constraints: no text, no letters, no scenery, no props, no watermark, no sprite sheet, no multiple poses, no smooth gradients, no soft shadows.
