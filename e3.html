How much work happens after recovery?

Model time is time spent in additional model calls. System time includes those calls, API round trips, checkpoint/session writes, and runtime inside the timed resumed execution phases.

This clock starts inside resumed execution.

It excludes failure detection, leader election, initial restore/setup, final artifact export, and retry control between timed phases. It is not elapsed time from the crash until the task finishes. Model time is contained in system time; do not add them.
